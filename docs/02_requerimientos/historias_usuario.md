### Académico

HU-010

Como director

Quiero registrar asignaturas

Para organizar el plan académico.

---

HU-011

Como director

Quiero asignar docentes a asignaturas

Para definir responsabilidades académicas.

---

HU-012

Como docente

Quiero visualizar mis asignaciones académicas

Para conocer mis responsabilidades.

---

HU-013

Como docente

Quiero visualizar mis estudiantes

Para gestionar adecuadamente mi grupo asignado.





**Asistencia**

- **HU-014:** Como docente, quiero registrar la asistencia de mis estudiantes por cada clase impartida, para llevar un control detallado del ausentismo por asignatura.
    
- **HU-015:** Como colaborador, quiero registrar mi hora de entrada y salida en el sistema, para cumplir con el control de asistencia institucional.
    
- **HU-016:** Como secretaria, quiero registrar o gestionar la asistencia de los colaboradores, para mantener el control en caso de contingencias o supervisiones.
    

**Evaluaciones y Calificaciones**

- **HU-017:** Como docente, quiero configurar los tipos de evaluación y sus ponderaciones para mis asignaturas, para estructurar cómo se calculará la nota del periodo.
    
- **HU-018:** Como docente, quiero registrar las calificaciones numéricas (0-20) de mis estudiantes en cada evaluación, para reflejar su rendimiento académico.
    
- **HU-019:** Como docente, quiero que el sistema calcule los promedios y los convierta automáticamente a la escala alfabética (AD, A, B, C), para cumplir con la normativa de reporte sin hacer el cálculo manual.
    

**Cierre de Año y Actas**

- **HU-020:** Como director, quiero generar las actas consolidadas por grado y sección, para tener el documento oficial con las notas finales de los estudiantes.
    
- **HU-021:** Como director, quiero que el sistema determine automáticamente la situación final del estudiante (Promovido o Repite) basándose en sus promedios, para evitar errores en la evaluación de permanencia.
    
- **HU-022:** Como director, quiero ejecutar el cierre del año lectivo según el calendario escolar, para bloquear modificaciones en el año actual y habilitar el proceso de matrícula del año siguiente.
